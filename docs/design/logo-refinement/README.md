# Angels logo refinement

Created in Figma on 18 November 2026. This is a proposed refinement of the supplied logo, keeping the uppercase ANGELS wordmark, overlapping script Angels and spaced CLINIC & BEAUTY descriptor.

[Review the editable Figma artwork](https://www.figma.com/design/WKseG6Qlc8DgpR1ERlWAZB?node-id=20-54).

- Stronger Cinzel Bold wordmark; Pinyon Script background signature; DM Sans SemiBold descriptor.
- Rich gold `#A4792C`, reversed gold `#E6CA91`, and single-colour aubergine `#382731`.
- Three native editable component variants, shared text styles and bound colour variables.
- Review board includes the supplied original, matching 260 px comparisons, and desktop 260 px / mobile 190 px header applications.
- Optical alignment and painted bounds checked. The script fits within the 1000 × 330 logo canvas.

`angels-logo-gold.svg`, `angels-logo-reversed.svg`, and `angels-logo-monochrome.svg` are transparent outlined vector exports from Figma. They contain no embedded photographs or external font dependencies. The editable lettering remains in Figma.

`review.png` is the visually checked final Figma review board.
